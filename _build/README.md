# 애원복지 웹진 제작 키트 (운영 노트)

신내종합사회복지관 소식지 「애원복지」를 업체 인쇄 대신 직접 만든 웹진으로 발행하기 위한 도구와 결정사항.
2026년 11월 50호(2021 가을) 합본으로 시제품을 만들어 검증함. 이 폴더(`_build`)는 웹에 공개되지 않는다(밑줄 폴더).

## 발행 정보
- 발간: 연 2회 (3월 봄호, 9월 가을호). 다음 제작: 2027년 2월 → 3월 발행(61호)
- 저장소: github.com/sin3400aewon/webzine (기관 공동계정 sin3400@snwc.or.kr, 사용자명 sin3400aewon)
- 웹진 주소: https://sin3400aewon.github.io/webzine/ (호수별 폴더 `vol50/`, `vol61/` …, 루트 index.html이 최신호로 이동)
- 기관 주소 연결 예정: webzine.snwc.or.kr 등 (홈페이지 도메인 업체에 CNAME 요청 필요, 아직 미설정)

## 원고 받는 방식 (기존 유지)
- 제작팀 회의로 구성안 → 사업 담당자 원고 → 담당자(노종범)가 한글 합본(.hwp) 작성
- 합본과 함께 페이지별 사진 원본 폴더도 받음 → 원본 사진을 우선 사용
- 합본에서 사진 위치가 빠지는 경우가 있음(50호 화보NEWS1) → 사진 내용으로 짝을 맞추고 담당자 확인

## 결정사항
- 형식: 웹사이트형 한 페이지 스크롤, 왼쪽 사이드 목차(책갈피)로 꼭지 이동. 상단 탭 없음
- 글꼴: 무료 글꼴만(Google Fonts: Gaegu 제호, Gowun Batang 제목, Gowun Dodum 본문)
- 디자인 소스: 무료 라이선스만. 표지 장식은 코드로 그림. 업체(디자인마루) 소스 사용 금지
- 계절 테마: 봄/가을 2종을 만들어 매년 재사용. 변경 요청이 있을 때만 수정 (현재 template.html = 가을)
- 표지 이미지: Canva 커넥터로 제작
- 사진: 초상권 동의를 받았거나 얼굴을 이모티콘으로 가린 사진만 사용
- 후원자 명단: 실명 공개
- 종이 출력본·인쇄용 PDF: 만들지 않음
- 조회수 집계: 필요 없음
- 검색 노출: 검토 중(미리보기)에는 `<meta name=robots content=noindex,nofollow,noimageindex>`로 차단, 정식 발행 때 제거
- 배포: 문자, 카카오톡 채널, 기관 홈페이지, 블로그(blog.naver.com/sinwelfare3400)에 링크 게시

## 검토·수정 방식
- 검토 링크: `…/webzine/volNN/?review=1` → 오른쪽 아래 "✎ 수정 요청" 버튼 (일반 주소에는 버튼 없음)
- 부장님·관장님은 클로드를 쓰지 않음 → 로그인 없이 버튼으로 요청
- 요청은 구글 앱스크립트 웹앱(review-config.js의 주소) → sin3400 드라이브의 "수정요청" 시트에 쌓임
  - 시트 열: 접수일시, 호수, 꼭지, 위치번호, 해당 내용, 요청 유형, 요청 내용, 요청자, 상태(접수/반영함/보류), 처리 메모, 페이지
  - 앱스크립트 코드: `Code.gs` (웹앱: 실행=나, 액세스=모든 사용자)
- 차수: 1차 편집위원(오탈자·사실) → 2차 부장님(내용·구성) → 3차 관장님(최종). 차수마다 모아서 일괄 반영
- 오탈자 몇 글자는 담당자가 GitHub 편집 화면에서 직접 수정 가능. 나머지는 Claude가 시트를 읽어 반영 후 상태를 "반영함"으로
- 디자인 수정은 선택지로: 테마 색, 꼭지 순서, 사진 배치(2·3·4장형), 표지 이미지
- 이전 버전은 GitHub 이력으로 되돌릴 수 있음

## 파일
- `extract_hwp.py` : 합본 HWP → dump.txt(본문·표·사진 순서) + 웹용 사진
- `template.html` : 웹진 틀(CSS/JS, 사이드 목차, 글자 크기, 사진 확대, 계좌 복사, 사업 찾기, 수정 요청 스크립트 연결)
- `build_example_vol50.py` : 50호 원고를 꼭지별 데이터로 옮겨 template에 넣는 예시. 새 호는 이 구조를 복사해 내용만 바꾼다
- `Code.gs` : 수정 요청 접수용 앱스크립트
- 저장소 루트 `review.js`, `review-config.js` : 검토 모드 스크립트와 접수 주소 (모든 호가 공유)
